# BookShare

P2P-платформа для обміну паперовими книгами між читачами одного міста. Клієнтська частина (React + TypeScript + Tailwind), дані зберігаються в LocalStorage.

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # production-збірка
```

Демо-акаунт: `maria@email.com` / `123456` (також `oleh@`, `anna@`, `ihor@`, `sofia@email.com`, той самий пароль).
Щоб скинути тестові дані, очистіть ключ `bookshare:v1` у LocalStorage браузера.

## Структура

- `src/store` — Zustand-стор з persist у LocalStorage (книги, бажане, запити, сповіщення, тема)
- `src/data/seed.ts` — тестові дані
- `src/lib/utils.ts` — зіставлення бажаного з бібліотеками (`findMatches`) та допоміжні функції
- `src/components` — UI-кіт, обкладинка книги, модалки, лейаут із сайдбаром
- `src/pages` — Вхід, Каталог, Моя бібліотека, Бажане, Збіги та сповіщення, Мої запити, Профіль

## Логіка статусів

- Підтверджений запит ставить книгу(и) у «Заброньовано».
- Для позики власник позначає «Передано» («У позиці»), потім «Книгу повернено» → «У мене».
- Обмін: власники книг не змінюються, після «Завершити обмін» книги повертаються в «У мене».

## Адміністратор

Демо-акаунт: `admin@email.com` / `admin123` (пункт «Адмін-панель» у меню, маршрут `#/admin`).
Вкладки: Статистика · Користувачі (пошук, блокування, видалення, призначення адмінів) · Книги (приховати, редагувати, видалити) · Запити (примусове скасування) · Жанри (додати/перейменувати/видалити).

## Для тестування

Демо-акаунти (пароль `123456`): maria, oleh, anna, ihor, sofia `@email.com`; адмін — `admin@email.com` / `admin123`.

- Дані спільні для всіх вкладок одного браузера, а ким ви увійшли — окремо для кожної вкладки. Тож щоб перевірити обмін між двома людьми, відкрийте дві вкладки й увійдіть у різні акаунти; зміни з'являються в іншій вкладці самі.
